Instructor only · Concepts

Interactive course

The pipeline, one stage at a time: 7 chapters, each with a live widget you play with right in the browser (re-split chunks, re-rank a hybrid retriever, hover a citation to see its source) and a “your turn” challenge with instant feedback. No API key, no install. It all runs in your browser. This is an instructor-facing demo surface, not distributed to learners, and is git-ignored.

python -m http.server 8540 --directory rag_course
Open course → or open rag_course/index.html directly, no server needed

Part B · Hands-on build

Guided workbook

All 9 activities, run against your own code. Edit the real src/ files in your IDE, then run that activity's checks from the workbook. They test exactly what's saved on disk, in a fresh subprocess every time, so there's no stale state. Stuck? Run the reference solution and compare. Every activity page has a floating “🧑‍💻 Code Assistant” chat. It's grounded in reference_solution/ and writes code for you to read and copy into src/ yourself. It's the only code assistant in this course, with no separate app. At the end there's a live “ask your own pipeline a question” section: the same knowledge portal as below, without leaving this tab.

python -m streamlit run app/workbook_app.py --server.headless true --server.port 8504
Open workbook →

Finished product

Knowledge portal

The finished Enterprise Knowledge System, running for real: ask a question, get a cited answer or an honest refusal, filtered by department. It shows what your finished pipeline looks like in production. It isn't a teaching surface, and it only answers correctly once your own src/ code passes the workbook's checks. The same ask/answer UI is also built into the workbook's Final Review page, so this standalone page is optional.

python -m streamlit run app/knowledge_portal.py --server.headless true --server.port 8503
Open portal →
Not running yet? Run the command above from the project root, then reload this link.
Run every command from the project root. The workbook and portal use different ports (8504 / 8503), so you can keep both open at once. The Code Assistant has no separate app or port. It lives inside the workbook (8504) as a floating panel. See README.md for full setup.
